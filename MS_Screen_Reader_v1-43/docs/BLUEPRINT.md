# MS Screen Reader v1.0 Blueprint
- Android AccessibilityService core
- TTS manager
- Basic focus/navigation foundation
- Gesture architecture
- Notification-reading architecture
- Caller-name announcer setting
- Power-button end-call setting (where supported)
- Volume-button answer setting (where supported)
- Quick-toggle/shortcut architecture

Future: advanced gestures, OCR, AI assistant, plugins, profiles, backup/restore and Braille.
